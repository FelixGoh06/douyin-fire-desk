# Contributing

1. Do not include real Cookie, token, browser profile, server address, or chat records in commits, screenshots, or issues.
2. Create a branch, make one focused change, and add or update tests when behavior changes.
3. Run `python -m pytest -q` and `bash -n install.sh scripts/*.sh` before opening a pull request.
4. Explain the use case, change, validation result, and any migration impact in the pull request.

Security-sensitive issues should follow [docs/SECURITY.md](docs/SECURITY.md) rather than public disclosure.
