# 使用手册

## 页面导航

- **首页**：查看账号、任务、近期运行和异常概览。
- **账号管理**：保存账号 Cookie、独立浏览器 Profile 和 Cookie 健康状态。
- **任务管理**：定义每天给谁发送、何时发送、发什么内容、是否检查火花。
- **执行记录**：查看所有历史批次；从某个任务开始的操作默认跳到该任务的实时记录。
- **OpenClaw**：开关自动通知、Cookie 健康检查与回复规则。
- **系统**：查看后台运行状态和 OpenClaw API 授权状态。

## 1. 添加账号

1. 打开 **账号管理**，点击新增账号。
2. 填写一个便于识别的账号名称。
3. 在 Cookie 输入框粘贴该抖音账号的 Cookie，保存。
4. Profile 保持默认即可。每个账号必须使用独立 Profile，避免登录状态互相覆盖。

Cookie 在服务器数据库中加密保存。页面不会提供明文查看入口。Cookie 过期后到同一页重新粘贴并保存。

状态含义：`有效` 表示最近检测成功；`失效` 表示需要更新 Cookie；`未保存` 表示还没有 Cookie；`未知` 表示尚未完成判断或当前执行异常。

## 2. 创建任务和好友

账号与任务是分开的：一个账号可以有多个任务；每个任务可配置多个好友昵称。

1. 打开 **任务管理**，点击新建任务。
2. 选择要使用的账号，填写任务名。
3. 添加目标好友昵称。昵称必须与抖音聊天列表中的显示名称一致。
4. 设置每日发送时间、消息模板、发送间隔和重试参数。
5. 保存并保持任务启用。

编辑任务时可随时修改好友昵称、增删好友、发送时间、消息内容和晚间检查设置。停用只是不再自动执行；删除会移除该任务和其目标好友。

## 3. 测试发送和实时日志

在任务详情或任务列表点击 **执行**。系统会创建一次实际运行，并自动打开该任务的实时日志。日志会显示浏览器启动、好友匹配、发送、重试和最终状态。

首次使用应先只创建一条熟悉的测试任务。确认日志中目标昵称匹配正确且发送成功后，再开启每日定时。

## 4. 每日定时续火

任务启用后，后台调度器会在该任务设置的时间自动运行。无需额外创建 Linux crontab。应用服务重启后会自动重新加载任务。

相同时间的多个任务会合为同一批：任务都完成后才发送一条 OpenClaw 汇总。不同时间的任务分别在各自时刻汇总。

## 5. 晚间检查火花

晚间检查依赖 OpenClaw 已接入，因此在没有接入时开关是禁用的。

1. 先按照 [OPENCLAW.md](OPENCLAW.md) 接入 OpenClaw。
2. 编辑任务，打开 **启用检查**，填写晚间检查时间并保存。
3. 可在任务页面点击 **检查火花** 立即测试；同样会打开实时日志。

检查结果分为：`未续`、`未知`、`已续`。`未知` 只表示本次无法可靠判断，不能视为未续。结果通知会把未续的人排在最前面。

## 6. Cookie 健康检查与通知

进入 **OpenClaw** 页面，每个账号都有一条 Cookie 健康规则：

1. 开启 **每日健康检查**。
2. 设置检查时间，默认是 `08:45`。
3. 开启 **Cookie 健康回复**。
4. 点击保存。

同一时刻的所有账号合为一条汇总，顺序是未保存、失效、未知、有效。未接入 OpenClaw 时，页面会提示并禁用需要推送的开关。

## 7. OpenClaw 页面中的回复任务

每个自动化任务有两个独立开关：

- **每日续火结果回复**：该任务所在续火批次结束后是否加入汇总通知。
- **晚间检查结果回复**：启用晚间检查后，该检查批次结束后是否加入汇总通知。

关闭某项开关不会停止任务本身，只是不向 OpenClaw 推送该项结果。

## 8. 修改或恢复配置

- 修改账号 Cookie：账号管理 -> 编辑账号 -> 粘贴新 Cookie -> 保存。
- 暂停任务：任务管理 -> 停用。历史记录不会删除。
- 删除任务：任务管理 -> 删除，确认后任务及目标好友一起删除。
- 重新接入 OpenClaw：服务器执行 `sudo bash /opt/douyin-fire-desk/scripts/setup-openclaw.sh`。
- 查看服务问题：服务器执行 `sudo bash /opt/douyin-fire-desk/scripts/doctor.sh`。
